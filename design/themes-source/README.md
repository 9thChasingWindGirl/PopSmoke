# 主题素材投放目录

把你已有的可替换主题放到这里，我抽成 `design/tokens.json` 里的 preset。

## 目录结构

```
themes-source/
  └─ <主题名>/                 # 例如 neon / retro / mono
       ├─ theme.css            # 颜色、描边、阴影相关的那部分（有就放，没有也行）
       ├─ screenshot.png       # 该主题下的一张页面截图（强烈建议）
       └─ notes.md             # 一句话：它跟默认主题差在哪
```

## 最小信息（四条，缺了我也能猜，但猜可能错）

1. **主色**（accent）是什么？压在它上面的文字是黑还是白？
2. **描边宽度**有没有变？（默认 4px，有些主题可能更细或更粗）
3. **阴影**有没有变？（默认是右下偏移 4px 的纯黑硬块，无模糊）
4. **字体 / 圆角**有没有变？

## 分两类处理

- **只有第 1 条变了** → 普通 preset。往 `tokens.json` 的 `themes` 里加一行就够了。
- **2/3/4 也变了** → 结构性主题。token 结构里会留一个 `recipe` 槽位，用来描述"这套主题换了一套几何配方"。这类主题在原生侧同样只改 JSON，页面代码不动。

## 格式无所谓

CSS 片段、截图、甚至一段文字描述都行。截图的信息量通常比 CSS 大 —— 因为风格是"看"出来的，不是"读"出来的。
